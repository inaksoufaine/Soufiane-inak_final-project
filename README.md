# وصف المشروع (README)

## حالة المشروع

**المشروع لا يزال قيد التطوير ولم يكتمل بعد.**

يتكون المشروع حالياً من خمس صفحات، بعضها مكتمل ومتجاوب مع مختلف أحجام الشاشات، بينما لا تزال صفحات أخرى تحتاج إلى بعض التعديلات والتحسينات، خاصة فيما يتعلق بالتصميم المتجاوب (Responsive Design).

## نبذة عن المشروع

يهدف هذا الموقع إلى تقديم معلومات وإرشادات حول كيفية التعامل مع القصص والتجارب الشخصية الحساسة، مع احترام مشاعر الأشخاص وتوفير بيئة آمنة تسمح لهم بالتعبير عن تجاربهم دون إصدار أحكام أو توجيه اللوم إليهم.

## الصفحات الموجودة في المشروع

### الصفحة الأولى: الصفحة الرئيسية (index.html)

- تم استخدام CSS وTailwind CSS في تصميم الصفحة.
- تم تصميم القسم الثالث (Section 3) باستخدام CSS.
- تم استخدام Tailwind CSS في باقي أجزاء الصفحة.
- تقدم هذه الصفحة نبذة عن الموقع وتوضح الخدمات والمعلومات التي يوفرها للزوار.

### الصفحة الثانية: مشاركة القصة

- تم إنجاز الصفحة بالكامل باستخدام Tailwind CSS.
- توضح كيفية مشاركة الشخص لقصته والتعبير عن تجربته دون الشعور بالحكم عليه أو توجيه اللوم إليه.
- تتضمن مجموعة من الإرشادات والخطوات التي تساعد الشخص على التحدث عن المواضيع الحساسة بطريقة مريحة وآمنة.

### الصفحة الثالثة: فهم القصة وحماية المعلومات الشخصية

- تم إنجاز الصفحة بالكامل باستخدام Tailwind CSS.
- توضح كيفية الاستماع إلى الشخص وفهم تجربته دون إصدار أحكام أو توجيه اللوم إليه.
- تتضمن إرشادات حول كيفية حماية المعلومات الشخصية والحفاظ على خصوصية الشخص.

### الصفحة الرابعة: كيفية تقديم المساعدة

- تم إنجاز الصفحة بالكامل باستخدام Tailwind CSS.
- توضح كيفية التعامل مع شخص مرّ بتجربة صعبة وتقديم الدعم المناسب له.
- تتضمن نصائح حول الأمور التي يجب القيام بها والأمور التي يجب تجنبها عند تقديم المساعدة.

### الصفحة الخامسة: تسجيل الدخول (Login)

- تحتوي الصفحة على واجهة خاصة بتسجيل الدخول.
- تطلب من المستخدم إدخال معلوماته الشخصية من خلال نموذج تسجيل الدخول.

## التقنيات المستخدمة

- HTML5
- CSS3
- Tailwind CSS
- DaisyUI

## شريط التنقل (Navbar)

تم الاعتماد على نموذج سابق لشريط التنقل، بالإضافة إلى الاستعانة بمكونات DaisyUI، ثم تم تعديل التصميم وتخصيصه ليتناسب مع شكل الموقع واحتياجاته.

كما تلقيت المساعدة من زملائي في تطوير وتحسين شريط التنقل.

## التصميم المتجاوب (Responsive Design)

تم العمل على جعل بعض صفحات الموقع متجاوبة مع مختلف أحجام الشاشات والأجهزة، لكن لم يتم استكمال هذه العملية في جميع الصفحات بعد، ولا تزال هناك بعض التعديلات والتحسينات المطلوبة.

## تقدم المشروع

يتوفر المشروع حالياً على خمس صفحات بمستويات مختلفة من الإنجاز. تم الانتهاء من بعض الصفحات والأقسام، بينما لا تزال أجزاء أخرى تحتاج إلى بعض التصحيحات والتحسينات، خاصة فيما يتعلق بالتنسيق والتصميم المتجاوب.

**ملاحظة:** المشروع لا يزال قيد التطوير، وسيتم استكمال العمل عليه وإجراء التعديلات اللازمة في المراحل القادمة.
